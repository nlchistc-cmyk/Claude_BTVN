[CLAUDE]

Kiem tra thu muc lam viec — phat hien workspace marketing-ads-personal-workspace
da ton tai san voi day du cau truc. Doc toan bo README.md va 3 file SKILL.md
(google-ads-copywriter, search-terms-negative-keyword, proposal-brief-summarizer),
script negative_keyword_analyzer.py, file sample_search_terms.csv, cac template
va example de kiem chung chat luong noi dung.

Chay thu CLI that de xac nhan script hoat dong:

  cd marketing-ads-personal-workspace
  python skills/search-terms-negative-keyword/scripts/negative_keyword_analyzer.py \
    --input skills/search-terms-negative-keyword/data/sample_search_terms.csv \
    --output skills/search-terms-negative-keyword/output/negative_keywords.csv \
    --product "tour trung quốc" \
    --keep "tour trung quốc,tour bắc kinh,tour thượng hải" \
    --level campaign \
    --mode balanced

Ket qua thuc te:
  Da phan tich 20 search terms.
  De xuat 12 tu khoa phu dinh (mode=balanced, level=campaign).
  Tong chi phi lang phi (confidence=High): 2520000
  Ket qua da luu tai: skills/search-terms-negative-keyword/output/negative_keywords.csv

Kiem tra file output negative_keywords.csv — dung 11 cot yeu cau
(negative_keyword, match_type, negative_level, reason, confidence,
source_search_term, campaign, ad_group, clicks, cost, conversions), 12 dong
ket qua, logic dung nhu SKILL.md mo ta.
